# Configuration

The app uses Dart compile-time environment values by default.

Run dev:

```sh
flutter run --dart-define-from-file=config/dev.json
```

Build production:

```sh
flutter build apk --dart-define-from-file=config/prod.json
flutter build ios --dart-define-from-file=config/prod.json
```

## Config Files

```txt
config/dev.json
config/staging.json
config/prod.json
```

These files are for client configuration only:

- `APP_ENV`
- `API_BASE_URL`
- `SENTRY_DSN`
- `ENABLE_NETWORK_LOGS`
- `ALLOW_INSECURE_HTTP_FOR_DEBUG`

Do not put server secrets, private keys, database passwords, admin tokens, or signing credentials in these files.

## Platform Flavors

Android and iOS flavors are intentionally not enabled by default because the
native project files are generated by your local Flutter SDK in `post_gen`.
Add platform flavors when you need separate bundle identifiers, icons, or app
names per environment.
